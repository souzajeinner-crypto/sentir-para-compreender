# Sentir para Compreender

> Avaliação Psicológica para Pessoas com Deficiência

_"A deficiência não está apenas no indivíduo, mas também nas barreiras impostas pela sociedade."_

## Sobre o Projeto

Site acadêmico interativo desenvolvido como trabalho de [disciplina] na [instituição]. O projeto explora a relação entre avaliação psicológica, deficiência, inclusão e acessibilidade digital.

## Funcionalidades

- Área teórica sobre avaliação psicológica e deficiência
- Experiências imersivas sobre barreiras sensoriais e sociais
- Área sonora com player acessível
- Quiz reflexivo sobre inclusão e acessibilidade
- Perspectivas da Psicologia (feed de autores)
- Relatos e depoimentos (com anonimização)
- Artigos produzidos pelo grupo
- Recursos de acessibilidade (contraste, fonte, teclado, VLibras)

## Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS

## Como rodar localmente

```bash
npm install
npm run dev
# Acesse http://localhost:3000
```

## Testes
